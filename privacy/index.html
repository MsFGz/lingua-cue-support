1. 适用范围与联系

本政策适用于 Lingua Cue iOS 应用，以及用于提供本政策和使用支持的文档网站。

运营者：史一阳。隐私与使用支持邮箱：yannshi101@gmail.com。

2. 麦克风与本地识别

只有在你主动点击“开始聆听”并授予系统麦克风权限后，应用才会收音。音频在本机内存中用于语音识别；正式发行配置不将录音写入文件，也不将音频发送到 AI 服务。

对话字幕在当前应用进程内存中处理，不作为会话记录写入本地文件。清空会移除当前对话内容；进程结束后内存不会继续保留。内存中的内容不等同于已从外部服务删除。

收音前请告知并取得其他对话参与者的适当同意。你可以随时停止聆听，也可以在 iOS 设置中撤销麦克风权限。应用不提供后台持续录音功能。

3. 术语与温习

内置词库和术语匹配在本机运行。只有你选择保存后，应用才将术语、解释、来源、会话标题和温习进度写入本机应用目录；保存对话术语不会自动保存完整字幕或私人原句。

温习文件使用 iOS 文件保护，并将所在目录标记为不纳入系统备份。应用没有自建云同步功能；这不构成对所有系统、设备转移或第三方备份工具行为的保证。

可以在温习中删除记录或个人词条。应用没有账户系统，也没有开发者服务器上的用户资料库。删除本机内容不会删除曾发送至 AI 服务的内容。

4. 可选 AI 问答

AI 为可选功能。只有配置服务并在发送确认中同意后，问题和本轮 AI 问答上下文才会通过 HTTPS 直接发送至你配置的服务。授权信息（API Key）通过请求头发送给同一服务，以完成鉴权。

问答不会自动附带对话页字幕、音频、温习记录或整个内置词库。你主动复制或输入到问题中的内容会一并发送。点击“整理为词条”会发送所选问答用于生成草稿，预览并确认后才写入温习。

聊天仅保存在当前进程内存中。新建问答或更改连接配置会清空当前聊天上下文。取消请求只能停止本机等待，不能保证服务端没有收到或保留已经发送的内容。

5. 单独授权的联网校对

联网校对默认关闭，每次会话需单独开启并确认发送范围及展示方式。启用后，应用向所选服务发送后续已提交句段（最多500字）、最多2条近期文字（各200字）和最多5个相关术语（各120字）。不发送音频、温习记录或其他问答。

停止、清空、切入后台或更改连接配置会关闭校对授权。已发送内容的服务端保留与删除由服务商处理；本机关闭开关不会撤回已经完成的网络发送。

6. 服务商、网络信息与留存

你配置的服务商是网络请求的接收方。请求会让接收方及必要的网络基础设施看到连接 IP、鉴权信息、请求内容及常规网络元数据。服务商所在地区、日志、留存、训练使用和删除方式，取决于其政策及你的账户设置。

应用不保证任意服务商都不留存、不训练或位于某一地区。发送前应阅读该服务的隐私政策与适用条款，并确认你有权发送这些内容；避免发送不必要的个人、机密或他人敏感信息。

应用未集成广告、跨应用跟踪或第三方统计 SDK，不将数据出售给广告商。可选 AI 功能涉及的服务商数据处理，按你选择的服务及本政策所述范围执行。

7. 连接配置与密钥

服务地址、模型标识、显示名称与 API Key 保存在本机钥匙串，设置为仅本设备解锁时可访问。更换服务地址必须重新输入密钥，不自动把原服务的密钥用于新地址。

可在连接设置中删除配置和密钥。卸载应用后钥匙串项目可能仍存在，因此需要删除密钥时应先在应用内删除连接配置。删除或更换本地密钥不等于撤销服务商账户的密钥；如有需要，应同时在服务商处撤销。

8. 通过邮箱联系我们

当你主动发送支持或隐私请求时，我们会收到你的邮件地址、邮件正文和你自愿提供的附件，仅用于处理问题、回复请求以及必要的后续沟通。

请只提供定位问题所需的信息，避免发送 API Key、私人对话、录音或不必要的敏感信息。支持邮件仅在处理请求及必要的安全、法定义务所需范围内保留；不再需要时删除或去标识化。

你可以通过上述邮箱提出查阅、更正或删除已发给我们的支持信息的请求。邮件由所使用的邮件服务处理，适用其隐私政策；删除支持邮件不会自动删除你本机或所选 AI 服务商保存的内容。

9. 访问文档网站

隐私政策和支持页面由 GitHub Pages 托管。网站没有登录、表单、广告、统计脚本或我们设置的跟踪 Cookie，也不自动连接任何 AI 服务。

为提供网页、保障服务和处理访问请求，GitHub 可能按其隐私声明处理连接 IP、设备与浏览器信息、访问时间等常规网络数据。GitHub 的处理与应用本机识别是不同的数据流。

GitHub 隐私声明：GitHub 隐私声明。主动点击联系邮箱会打开你选择的邮件客户端，不会由网页直接提交内容。

10. 外部链接与政策更新

查看来源、服务商网站或公开政策时，只有主动打开链接才访问相应网站；这些网站有各自的隐私规则。应用内政策与许可正文可以离线阅读。

如果数据处理范围发生变化，将在新版本中更新本政策及相应发送确认。本政策的更新日期显示在页面顶部。
