1. 适用范围与联系

本政策适用于 Lingua Cue iOS 应用，以及用于提供本政策和使用支持的文档网站。

运营者：史一阳。隐私联系邮箱：yannshi101@gmail.com。

2. 离线首发版本范围

本候选为 Lingua Cue 1.0 离线版本，提供本机语音识别、术语提示、手动输入与温习。不提供在线 AI 问答、联网校对、服务配置或 API Key 输入，不创建 AI 服务请求，也不读取历史开发版的 AI 连接配置。

应用没有开发者数据上传、广告、跨应用跟踪或第三方统计 SDK。只有主动打开来源、隐私或支持等外部链接时，系统才会访问对应网站；网站可能接收 IP 和常规访问元数据。

3. 麦克风与本地识别

只有在你主动点击“开始聆听”并授予系统麦克风权限后，应用才会收音。音频在本机内存中用于语音识别；正式发行配置不将录音写入文件，也不将音频发送到 AI 服务。

对话字幕在当前应用进程内存中处理，不作为会话记录写入本地文件。清空会移除当前对话内容；进程结束后内存不会继续保留。

收音前请告知并取得其他对话参与者的适当同意。你可以随时停止聆听，也可以在 iOS 设置中撤销麦克风权限。应用不提供后台持续录音功能。

4. 术语与温习

内置词库和术语匹配在本机运行。只有你选择保存后，应用才将术语、解释、来源、会话标题和温习进度写入本机应用目录；保存对话术语不会自动保存完整字幕或私人原句。

温习文件使用 iOS 文件保护，并将所在目录标记为不纳入系统备份。应用没有自建云同步功能；这不构成对所有系统、设备转移或第三方备份工具行为的保证。

可以在温习中删除记录或个人词条。应用没有账户系统，也没有开发者服务器上的用户资料库。

5. 通过邮箱联系我们

当你主动发送支持或隐私请求时，我们会收到你的邮件地址、邮件正文和你自愿提供的附件，仅用于处理问题、回复请求以及必要的后续沟通。

请只提供定位问题所需的信息，避免发送 API Key、私人对话、录音或不必要的敏感信息。支持邮件仅在处理请求及必要的安全、法定义务所需范围内保留；不再需要时删除或去标识化。

你可以通过上述邮箱提出查阅、更正或删除已发给我们的支持信息的请求。邮件由所使用的邮件服务处理，适用其隐私政策；删除支持邮件不会自动删除你本机或所选 AI 服务商保存的内容。

6. 访问文档网站

隐私政策和支持页面由 GitHub Pages 托管。网站没有登录、表单、广告、统计脚本或我们设置的跟踪 Cookie，也不自动连接任何 AI 服务。

为提供网页、保障服务和处理访问请求，GitHub 可能按其隐私声明处理连接 IP、设备与浏览器信息、访问时间等常规网络数据。GitHub 的处理与应用本机识别是不同的数据流。

GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement。主动点击联系邮箱会打开你选择的邮件客户端，不会由网页直接提交内容。

7. 外部链接与政策更新

查看来源、服务商网站或公开政策时，只有主动打开链接才访问相应网站；这些网站有各自的隐私规则。应用内政策与许可正文可以离线阅读。

如果数据处理范围发生变化，将在新版本中更新本政策及相应发送确认。本政策的更新日期显示在页面顶部。
